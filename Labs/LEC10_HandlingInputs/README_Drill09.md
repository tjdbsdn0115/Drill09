# Drill09 — 소년 상하좌우 이동 및 방향 바꾸기

## 실행

Python과 pico2d가 필요합니다. pico2d가 없다면 `python -m pip install pico2d`로 설치합니다.

```powershell
python animation_homework.py
```

`animation_homework.py`, `animation_sheet.png`, `TUK_GROUND.png`를 같은 폴더에 둡니다.
이미지는 파이썬 파일 위치를 기준으로 찾으므로 VS Code에서 다른 작업 폴더를 열어 실행해도 됩니다.

## 조작과 과제 조건

| 조건 | 구현 |
|---|---|
| 상하좌우 방향키로 이동 | 누르고 있는 키를 집합으로 기록하여 x, y를 변경 |
| IDLE 상태에서는 IDLE 애니메이션 | 실제 위치가 바뀌지 않으면 IDLE 줄의 8프레임 반복 |
| 이동 방향의 애니메이션 | 왼쪽·오른쪽 이동 프레임을 각각 선택 |
| 위아래 이동 시 기존 방향 유지 | 위·아래 키는 좌우를 바라보는 facing 값을 바꾸지 않음 |
| 화면 경계를 벗어나지 않음 | 캐릭터 프레임 절반 크기 50을 고려하여 x, y 제한 |
| animation_sheet.png 사용 | 강의의 원본 스프라이트 시트 사용 |
| TUK_GROUND.png 배경 | 원본 배경을 1000×800 창에 맞춰 표시 |

방향키를 놓으면 정지하며 마지막으로 바라본 방향의 IDLE을 재생합니다.
반대 방향키를 함께 누르면 해당 축 이동이 상쇄됩니다. 대각선도 같은 속도로 이동합니다.
경계에 막혀 실제로 움직이지 않을 때는 IDLE을 재생합니다.
ESC 또는 창 닫기 버튼으로 종료합니다. 창 포커스를 잃으면 눌림 상태를 비워 이동이 계속되는 현상을 막습니다.

## 코드 읽기

- `handle_events()`: 방향키 눌림/해제, 마지막 좌우 방향, 종료 입력 처리
- `update(dt)`: 이동, 경계 제한, IDLE/MOVE 상태, 애니메이션 프레임 계산
- `draw()`: 배경과 해당 상태·방향의 캐릭터 프레임 표시
- `main()`: 이미지 준비, 이벤트·갱신·출력 반복, 캔버스 정리

스프라이트 시트의 한 프레임은 100×100이며 각 줄에 8프레임이 있습니다.
pico2d의 아래쪽 y=0을 기준으로 행은 다음과 같습니다.

| 행 | 상태 |
|---:|---|
| 0 | 왼쪽 이동 |
| 1 | 오른쪽 이동 |
| 2 | 왼쪽 IDLE |
| 3 | 오른쪽 IDLE |

`MOVE_SPEED = 250.0`은 초당 이동 픽셀 수, `ANIMATION_FPS = 10.0`은 초당 애니메이션 프레임 수입니다.
`WIDTH`, `HEIGHT`를 바꾸면 창과 배경 크기 및 경계 제한도 함께 바뀝니다.

## 검증

방향 이동, 수직 이동의 방향 유지, IDLE 재생, 키 해제, 반대키·반복키,
네 경계와 역방향 탈출, 모서리·경계 따라 이동, 대각선 속도,
프레임 시간 독립성, 포커스 해제, ESC·창 종료, 스프라이트 행 선택을 11개 자동 검사로 확인했습니다.
실제 Pico2D의 이미지 로딩과 IDLE·경계 화면 렌더링도 확인했습니다.
